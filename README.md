# ML From Scratch

Starting from nothing but `numpy` we implement a transformer architecture, no LLMs involved in implementing `src/`.

* "Neural Networks from Scrath" by Harrison Kinsley and Daniela Kukiela.
* Sebastian Raschka's Blogs: https://sebastianraschka.com
