# ML From Scratch

Starting from nothing but `numpy` we implement a transformer architecture, no LLMs or external ML libraries involved in implementation.

Main resources:
* "Neural Networks from Scrath" by Harrison Kinsley and Daniela Kukiela
* Sebastian Raschka's Blogs: https://sebastianraschka.com
* 3Blue1Brown's YT channel: https://www.youtube.com/@3blue1brown
* labml's Annotated Research Paper Implementations: https://nn.labml.ai/
